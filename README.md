# WorkBuddy · 工作智能助手（独立应用版）

融合 **WorkBuddy 任务拆解能力** 与 **ima 长文本精读能力** 的一站式工作智能助手。
纯前端应用：**不依赖扣子、不需要 API Key、文件不上传服务器**，本地解析、本地生成。

## ✨ 功能

| 能力 | 说明 |
| --- | --- |
| 📚 文档精读（ima） | 上传 PDF / Word / TXT 或粘贴长文本，本地精读全文，自动提取**关键词、内容框架、摘要**，忠于原文不编造 |
| 🧰 任务工作台（WorkBuddy） | 一次生成完整成品：**幼儿园教案（教案+说课稿+PPT脚本）**、工作方案、工作总结、PPT文稿、数据表格、文案、分析报告 |
| 🧩 任务拆解 | 把复杂任务自动拆成可执行的多步骤清单 |
| 📲 手机 App 体验 | PWA 应用，手机浏览器访问后「添加到主屏幕」，像 App 一样使用 |
| 🔒 隐私安全 | 所有解析与生成都在浏览器本地完成，文档不上传、不存储 |

## 🚀 部署到 GitHub（获得独立网址）

1. 在 GitHub 新建仓库（如 `workbuddy-app`），选择 **Public**
2. 把本文件夹内的**所有文件**上传到仓库（保持目录结构不变）
3. 进入仓库 **Settings → Pages**：
   - Source 选择 **Deploy from a branch**
   - Branch 选择 `main`（或你的默认分支），文件夹选 `/ (root)`
   - 点击 **Save**
4. 等待 1-2 分钟，访问 `https://你的用户名.github.io/workbuddy-app/` 即可使用

> 也可以部署到 Vercel / Netlify / 腾讯云静态托管等，直接拖入文件夹即可。

## 📱 手机使用（下载/安装）

打开部署后的网址（手机浏览器），然后：

- **iPhone（Safari）**：点底部「分享」按钮 → 「添加到主屏幕」→ 确认
- **Android（Chrome）**：点右上角「⋮」菜单 → 「添加到主屏幕」/「安装应用」
- 添加后主屏幕会出现 **WB** 图标，点击即可像原生 App 一样全屏使用
- 首次打开联网加载后，核心页面会缓存，之后可**离线使用**

## 🖥️ 本地打开

无需部署也能用：双击 `index.html` 即可（PWA 安装功能需要部署后生效，其余功能本地全部可用）。

## 💡 使用提示

- **幼儿园教案**：选年龄段 + 领域 + 主题 + 用途（比赛/教资/日常），一次生成教案 + 说课稿 + 卡通风PPT脚本
- **文档精读**：上传 PDF/Word 后自动出关键词、框架、摘要，可复制摘要、下载全文
- **生成内容**：所有生成结果都可一键复制或下载 Markdown / CSV
- 数据全部原创模板组合生成，符合《纲要》《指南》精神，不出现"参考某网站"表述
